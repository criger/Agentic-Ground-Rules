# Project instruction template

This directory is a flexible template, not a real project.

- Read `README.md` and begin with `project-intake.md`.
- Select only the files and sections the real project needs.
- Do not fill gaps by guessing. Inspect source/runtime evidence or ask the project owner.
- Adapt structure, language and detail to the actual project.
- Create finished context in a separate directory under `projects/`; do not make this template project-specific.
- Keep global requirements shared and document only real project specializations or exceptions.
