# Project context

Each child directory is either a reusable template or one fictional example project.

- Select only the project relevant to the task.
- Read its `AGENTS.md` and `README.md` before other files.
- Do not treat fictional example repositories, commits or runtime claims as real resources.
- For a real project, verify the current source branch, code, tests and runtime before implementation or firm technical conclusions.
- Project files specialize the global instructions and should not copy them.
- Preserve intentional differences when a project does not need the full template.
